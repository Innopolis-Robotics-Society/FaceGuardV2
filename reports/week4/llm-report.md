# LLM Usage in FaceGuard Project

During the current sprint, Large Language Models (LLMs) were utilized for the following tasks:

1. **Computer Vision Configuration:** Assisted in drafting initial pipeline configurations for face detection and exploring liveness detection algorithms.
2. **Analytics Automation:** Analyzed meeting transcripts with the client and automatically extracted key requirements (UAT, Quality Requirements) for reporting.
3. **Code Refactoring:** Generated templates to extend SQL scripts into fully functional CRUD operations for the database interface.
